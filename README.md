# 💜 SmartDay AI

**SmartDay AI** — це інтелектуальний планувальник дня, який використовує штучний інтелект для створення персонального розкладу на основі списку завдань користувача.

Мета проєкту — допомогти ефективніше організовувати свій час, розподіляти завдання протягом дня та відстежувати власний прогрес.

## ✨ Основні можливості

- 🤖 **AI-генерація розкладу** — автоматичне створення плану дня на основі введених завдань.
- ⏱️ **Розподіл часу** — визначення орієнтовної тривалості кожного завдання.
- 📝 **Редагування завдань** — можливість змінювати назву, тривалість та нотатки.
- 🗑️ **Видалення завдань** — можливість прибирати непотрібні справи.
- ✅ **Відстеження прогресу** — позначення виконаних завдань та перегляд статистики.
- 📊 **Індикатор прогресу** — візуальне відображення виконання плану.
- 💡 **AI-нотатки** — автоматичне створення коротких підказок до завдань.
- 🌙 **Темна та світла теми** — вибір зручного оформлення.
- 🔄 **Створення нового розкладу** — можливість швидко почати планування заново.

## 🚀 Як запустити проєкт

### 1. Клонування або завантаження проєкту

Завантажте проєкт на свій комп'ютер та відкрийте його папку в терміналі.

### 2. Створення віртуального середовища

```bash
python -m venv venv
```

### 3. Активація середовища

Для Windows Git Bash:

```bash
source venv/Scripts/activate
```

### 4. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 5. Налаштування API-ключа

Створіть файл `.env` у головній папці проєкту та додайте:

```env
OPENAI_API_KEY=your_groq_api_key
```

Замість `your_groq_api_key` вставте власний API-ключ Groq.

### 6. Запуск застосунку

```bash
python app.py
```

Після запуску відкрийте у браузері:

http://127.0.0.1:5000
